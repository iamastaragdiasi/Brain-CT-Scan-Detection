#  Brain CT Scan Detection System

AI-powered brain tumor detection and CT scan classification system using Deep Learning and Computer Vision.

---

## 📌 Project Overview

This project analyzes brain CT scan images to detect and classify tumors using Artificial Intelligence and Machine Learning models. The system is designed to assist in medical image analysis through automated prediction workflows.

---

## 🚀 Features

- Brain tumor detection
- CT scan image analysis
- Deep learning-based prediction
- Medical imaging workflow
- AI/ML integration
- Classification system

---

## 🛠️ Technologies Used

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/iamastaragdiasi/Brain-CT-Scan-Detection.git
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

### Run Backend

```bash
python main.py
```

---

### Run Frontend

```bash
npm install
npm run dev
```
